## UI and UI Framework

Thus far in my journey to becoming a Computer Engineer, I have always wanted to have a crack at front-end development. When I heard what we would be doing in this class, essentially building a full-stack website for the final project, I was eager to tackle the tasks and learn more about things like the UI. Recently we have been getting into HTML and CSS and just like I imagined it was super rewarding being able to see how changes are implemented in real time. As we got more familiar with HTML and CSS we began to implement a UI Framework, Bootstrap5. To ensure everyone is on the same page, a UI Framework essentially comes with pre-built collections of ready-made UI elements like buttons, navbars, dropdowns, etc. This ensures the easier customizability of the elements, standard for formatting, and even helps to build the UI quickly.

## My Experience with UI Frameworks
	
When first learning about Bootstrap5 I was honestly a little confused as to what it was and what it was used for. However, going through it I now understand and can definitely see the usefulness of it as well as other UI Frameworks. I think going through all the different WOD homework, practice, and actual WODs, I was able to see how using things like the prebuilt collections helped to design websites, especially in things like navbars. While you can format those specific parts in a certain way using HTML and CSS, having the prebuilt collections helped to keep the format and design consistent. Throughout these WODs, we constantly made navbars which were essential in every website. It was very useful to have things like navbar-collapse which makes it into a small menu when the screen gets smaller, navbar-toggler the button for the collapsed menu, navbar-nav container for the list of navigation lists, etc. These are some of the base components when creating a navbar. This goes for a lot of other collections such as containers which help to organize and format your design. I’d say for me that there are just a lot of collections to remember. When learning this there was a heavy learning curve of the different collections and a lot of remembering what specific thing does what and the possibilities of designing. For me, I always specifically had trouble aligning the different items in the taskbar and moving it either more left or more right. Also when implementing a photo in a background or just on the website. However, I feel that UI Frameworks are really useful when designing websites due to their predictability and consistency.

## Conclusion


Overall though I find UI frameworks kind of tedious to understand I believe it is a very useful tool if you can really understand what each part does. For example, I was able to use a similar format for each navbar across the different websites and just change a little bit of alignment and content within. It really is able to streamline your design process as opposed to just using raw HTML and CSS. I believe that UI Frameworks are an important tool in regard to consistent formatting, time efficiency, and customization when building UIs. I will continue to progress my skills and get more used to Bootstrap5 to help my UI design skills.
